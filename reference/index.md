# Package index

## Commands

- [`stata_run()`](https://dostata.jamesatkins.com/reference/stata_run.md)
  : Run a Stata command
- [`stata_path()`](https://dostata.jamesatkins.com/reference/stata_path.md)
  : Get or set the path to the Stata executable

## Transfer Data between R and Stata

- [`stata_data_in()`](https://dostata.jamesatkins.com/reference/stata_data_in.md)
  : Transfer data from R to Stata
- [`stata_data_out()`](https://dostata.jamesatkins.com/reference/stata_data_out.md)
  : Transfer data from Stata to R

## Sessions

- [`stata_start_session()`](https://dostata.jamesatkins.com/reference/stata_start_session.md)
  : Start a new session of Stata running in batch mode
- [`stata_close_session()`](https://dostata.jamesatkins.com/reference/stata_close_session.md)
  : Close a Stata session
- [`stata_default_session()`](https://dostata.jamesatkins.com/reference/stata_default_session.md)
  : Get the default Stata session

## Advanced

- [`stata_evaluate()`](https://dostata.jamesatkins.com/reference/stata_evaluate.md)
  : Evaluate Stata commands and return details of their evaluation
